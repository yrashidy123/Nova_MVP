Nova Assist in the mobile app

A prototype of the customer chat embedded in the Nova Bank app, using the same guarded pipeline and the team’s synthetic data as the console. The phone on the left is a mock of the host app; only the chat is Nova Assist.

In this prototype

  • Chat only: no evals, queue, audit or customer picker inside the app
  • Opens from a transaction, a card or Help, with that context attached
  • Full-screen sheet, native header, 44 pt targets, 16 px input
  • Dispute timeline, card delivery and payment cards
  • Plain source labels; tap one for the full source
  • No internal check trace or “Blocked” labels
  • Whole layout mirrors in Arabic, with Arabic dates and digits
  • Handoff ticket with status and a waiting banner
  • Card number, PIN and OTP warning while typing
  • Three context-aware suggestions, typing indicator, thumbs up/down, offline state
  • Follows dark mode and text size

Native app work (not in a web prototype)

  • Pass a short-lived session token to the web view; never a customer ID in the URL
  • Push notification when an agent replies
  • Block screenshots of the chat on Android (FLAG_SECURE)
  • Keep history between visits; clear on sign-out
  • Deep links from chat buttons into native screens
